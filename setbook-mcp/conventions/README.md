# conventions/

- `CONVENTIONS.md` — the versioned rule set served to AI tools by the
  `get_songbook_conventions` MCP tool. This file is published to the repo;
  it contains rules only, no song content.
- `examples/` — example song files the user submits so the rules can be
  refined. **Private working material: never push this directory to the
  public repo.** The publish script skips it. The conventions doc records
  which examples informed each version; the examples themselves stay here.
